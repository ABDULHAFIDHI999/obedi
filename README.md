# Obedi — Odoo 20 Community Addons

| Module | Maelezo |
|---|---|
| [`contact_football_team`](contact_football_team/) | Inaongeza chaguo la **Football Team** kwenye kila contact |
| [`kpi_management`](kpi_management/) | KPI na Scorecards |
| [`parcel_transport`](parcel_transport/) | Usimamizi wa usafirishaji wa vifurushi (inahitaji `swala_sms` na `website`) |
| [`swala_sms`](swala_sms/) | Muunganiko wa SwalaSMS |

## Usakinishaji
Ongeza repo hii kama custom addons repository (root ya repo ndiyo addons path).
Kisha: **Developer Mode → Apps → Update Apps List**, ondoa filter ya *Apps* na tafuta jina la module.
